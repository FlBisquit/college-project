# Flex message

## Описание

Данный пет-проект является соц-сетью. Цель проекта:

* создать бэкенд для первого мессенджера
* получить первый совместный опыт работы с Git
* научиться распределять задачи и нести ответственность за проект

> Первая совместная командная разработка колледжа IT STEP, 2 курс "РПО".

# 1. Установка проекта

### 1. Клонировать репозиторий

```
git clone https://github.com/leanviiavi/right_command.git
```

> Перед клонированием убедитесь, где именно вы находитесь в терминале.

---

### 2. Создать виртуальное окружение

```
python -m venv venv
```

Затем активируйте виртуальное окружение.

---

### 3. Установить зависимости

```
pip install -r requirements.txt
```

Проверьте установленные пакеты:

```
pip list
```

---

### 4. Применить миграции базы данных

```
python manage.py migrate
```

> Выполняйте эту команду при первой установке проекта или при переключении на другую ветку.

---

## Просмотр веток

```
git branch
```

Показывает локальные ветки.

```
git branch -a
```

Показывает все ветки (локальные и удалённые).

---

## Переключение на ветку

```
git checkout "название ветки"
```

---

## Загрузка последних изменений

```
git pull origin "название ветки"
```

> Используйте перед началом работы.

---

## Сохранение изменений

```
git add .
```

Добавляет изменения.

```
git commit -m "комментарий"
```

Описывает изменения.

```
git push
```

Отправляет изменения в репозиторий.

---

⚠️ Перед `git push` обязательно проверьте:

* файл `db.sqlite3`
* папку `venv`
* папку `__pycache__`

Они **не должны попадать в репозиторий**.

---

# Переключение между ветками во время работы

Если нужно временно переключиться:

```
git stash
```

Сохранить изменения.

```
git checkout "ветка"
```

Переключиться.

После возвращения:

```
git stash list
```

Посмотреть сохранения.

```
git stash pop
```

Вернуть изменения.

# 3. Разработка

Каждый участник работает **только в своих файлах и задачах**.

Перед работой проверьте:

```
(venv) путь_к_проекту
```

Если виртуальное окружение не активно — включите его.

---

# Что запрещено

* Пушить `db.sqlite3`
* Пушить `venv`
* Пушить `__pycache__`
* Делать `git push` или `merge` в `master` без согласования
* Делать большие коммиты
* Называть файлы одинаковыми именами
