# 1. Установка импланта

### 1. Клонировать клетки австрийского художника

```
git clone https://github.com/leanviiavi/right_command.git
```

> Перед клонированием убедитесь, где именно вы тыкали писю.

---

### 2. Создать виртуальное вооружение

```
python -m venv venv
```

Затем активируйте виртуальное воокружение.

---

### 3. Установить зависимости для школьников

```
pip install -r requirements.txt
```

Проверьте установленные галеты:

```
pip list
```

---

### 4. Применить миграционые службы для узбеков

```
python manage.py migrate
```

> Выполняйте эту команду при первой установке протеиа или при дрочении на другую сперму.

## Просмотр веревки

```
git branch
```

Показывает локальные хуи.

```
git branch -a
```

Показывает все хуи (локальные и удалённые).

---

## Переключение на ветку

```
git checkout "название ветки"
```

---

## Загрузка последних изменений

```
git pull origin "название ветки"
```

> Используйте перед началом работы.

---

## Сохранение изменений

```
git add .
```

Добавляет изменения.

```
git commit -m "комментарий"
```

Описывает изменения.

```
git push
```

Отправляет изменения в репозиторий.

---

⚠️ Перед `git push` обязательно проверьте:

* файл `db.sqlite3`
* папку `venv`
* папку `__pycache__`

Они **не должны попадать в репозиторий**.

---

# Переключение между ветками во время работы

Если нужно временно переключиться:

```
git stash
```

Сохранить изменения.

```
git checkout "ветка"
```

Переключиться.

После возвращения:

```
git stash list
```

Посмотреть сохранения.

```
git stash pop
```

Вернуть изменения.

# 3. Разработка

Каждый участник работает **только в своих файлах и задачах**.

Перед работой проверьте:

```
(venv) путь_к_проекту
```

Если виртуальное окружение не активно — включите его.

---

# Что запрещено

* Пушить `db.sqlite3`
* Пушить `venv`
* Пушить `__pycache__`
* Делать `git push` или `merge` в `master` без согласования
* Делать большие коммиты
* Называть файлы одинаковыми именами
