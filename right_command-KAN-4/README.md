### 1. Клонировать репозиторий:

```

```
> Перед тем как клонировать, убедись где ты его скачиваешь в терминале


### 1. Просмотр веток

Сначало посмотрите какие есть ветки

```
git branch
```
> Список локальных веток (тоесть у тебя на компьютере)

```
git branch -a
```
> Cписок всех веток (локальные + удаленные на Github)

### 2. Выберите свою ветку

```
git checkout "название ветки"
```
> Переключиться на определённую ветку

### 3. Загрузить последних изменений в проект

```
git pull origin "название ветки"
```
> Вводи эту команду перед тем как работать (если ты работал сначало в колледже а теперь дома)

### 4. Сохранить изменения (когда поработал)

```
git add .
```
> Команда добавит все твои измения

```
git commit -m "комментарий"
```
> Подпиши что ты сделал (подписывай нормально чтобы патом всё не искать)

```
git push
```
> Отправь изменения в репозиторий

### 5. Переключение на другую ветку

Например вы хотите переключиться из одной ветки в другую, 
чтобы посмотреть все изменения своего коллеги, 
но при этом не сделали коммит и еще не доработали всё что ты еще делаешь

```
git stash
```
> Сохраните состояние проекта, перед тем как переключиться

```
git checkout "название ветки"
```
> Переключиться на другую ветку, дальше git pull origin... чтобы всё загрузить и посмотреть

После того как всё проверил, нужно вернуться обратно в свой проект

```
git checkout "название ветки"
```
> Переключиться на свою ветку

```
git stash list
```
> Сначала проверь на каких ветках есть сохранения (должно отоброжаться что-то вроде stash@{номер}: WIP on "НАЗВАНИЕ ВЕТКИ": ...)

```
git stash show
```
> Посмотри что было изменено в последний раз

```
git stash pop
```
> Теперь вводи это чтобы вернуться к сохранению и сразу удалить из истории сохранения (тогда в git stash list он пропадёт)
